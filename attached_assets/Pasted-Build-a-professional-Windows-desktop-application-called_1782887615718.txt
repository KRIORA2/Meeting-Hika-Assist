Build a professional Windows desktop application called **Hika**.

## Project Overview

Hika is a private AI meeting assistant that helps users during live meetings by listening to the meeting audio, generating live transcripts, understanding the conversation, and providing real-time AI answers, technical explanations, suggestions, code, documentation, and meeting insights.

The application should look modern, premium, lightweight, and extremely fast.

The overall UI should follow the design style of ChatGPT Desktop, Notion, and Linear.

# Floating AI Overlay (PiP Mode)

Create a separate floating assistant window.

This window should behave like a Picture-in-Picture assistant.

Requirements

* Always on top
* Draggable
* Resizable
* Rounded corners
* Glassmorphism effect
* Modern animations
* Adjustable transparency
* Compact mode
* Expand mode
* Auto hide
* Pin option

The overlay should only display

* Suggested Answers
* Key Points
* Current Question
* Confidence Score
* Important Alerts

No transcript should appear inside the floating overlay.

Only AI suggestions.

The overlay should feel like a smart assistant floating on the user's desktop.

It must never interrupt the user's work.

The user should be able to move it anywhere.

The transparency should be adjustable from 20% to 100%.

# Screen Sharing Experience

When the user shares their screen during Microsoft Teams, Zoom, or Google Meet, Hika should provide a **Private Assistant Mode**.

Design the application architecture so that the assistant is intended to remain a personal reference for the user during meetings wherever the operating system and screen-sharing application support private overlays or window-specific sharing.

Include settings such as:

* Private Assistant Mode
* Overlay Transparency
* Overlay Position
* Overlay Size
* Auto Hide
* Click Through Mode
* Lock Position

The application should gracefully handle different screen-sharing scenarios and clearly indicate when the overlay may be visible depending on the user's sharing method.
